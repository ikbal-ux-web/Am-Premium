REST API Reference

Base URL: https://alightmotion.qsr.web.id
Gunakan endpoint di bawah untuk mengintegrasikan generator Alight Motion Premium ke aplikasi atau bot Anda.

CORS Enabled GET only JSON Response

No Authentication Required

API ini tidak memerlukan API key. Cukup panggil endpoint dengan parameter yang diperlukan.

GET /api/email-prem

Kirim permintaan email verifikasi ke alamat target. Setelah berhasil, user harus membuka email dan menyalin URL verifikasi.

Query Parameters

Name Type Required Description
email string required Alamat email target yang akan diaktifkan

Example Request

curl -X GET "https://alightmotion.qsr.web.id/api/email-prem?email=user@example.com"

Success Response (200)

{
  "status": true,
  "code": 200,
  "success": true,
  "message": "Permintaan berhasil diproses. Masukkan URL verifikasi.",
  "email": "user@example.com",
  "data": null
}

Error Response

{
  "status": false,
  "code": 400,
  "message": "Parameter \"email\" is required."
}
GET /api/vertif-prem

Aktivasi premium menggunakan URL verifikasi yang didapat dari email.

Query Parameters

Name Type Required Description
email string required Email yang dipakai saat memanggil /api/email-prem
link string required URL / tautan verifikasi dari email (alias: url)

Example Request

curl -X GET "https://alightmotion.qsr.web.id/api/vertif-prem?email=user%40example.com&link=https%3A%2F%2Fexample.com%2Fverify%2Fxxx"

Success Response (200)

{
  "status": true,
  "code": 200,
  "success": true,
  "message": "Verifikasi berhasil. Premium aktif.",
  "data": {
    "success": true,
    "user": { "...": "..." },
    "idToken": "...",
    "premium": { "...": "..." }
  }
}

Error Response

{
  "status": false,
  "code": 400,
  "message": "Parameter \"email\" dan \"link\" (atau \"url\") wajib diisi."
}

Alur Penggunaan

  1. Panggil /api/email-prem dengan email target.
  2. User membuka kotak masuk / spam email dan menyalin link verifikasi.
  3. Panggil /api/vertif-prem dengan URL tersebut.
  4. Jika berhasil, akun akan berstatus premium.

  `${BASE}/api/email-prem?email=${encodeURIComponent("user@example.com")}`
